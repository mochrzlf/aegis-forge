# Mobile AppSec Guardian

Mandatory security standard for mobile apps before staging/store release.
Source of truth: `docs/security/mobile-security-checklist.md` (this skill
summarizes it; the checklist governs on conflict).

## 1. Credential & Data Storage

- ❌ **Never** store tokens, passwords, or PII in plaintext `SharedPreferences`,
  `NSUserDefaults`, or plain `.txt`/`.json` files.
- ✅ Session credentials go in `EncryptedSharedPreferences` with the master key
  generated by the **Android Keystore System** (AES-256-GCM / AES-256-SIV).
- ✅ Local Room/SQLite databases with sensitive data use **SQLCipher**, with the
  DB key derived from the Keystore.
- ✅ Enable `FLAG_SECURE` on every Activity/screen showing sensitive data
  (blocks screenshots, recordings, and task-switcher previews).

## 2. Network Security

- ✅ `network_security_config.xml` declares `cleartextTrafficPermitted="false"`;
  all traffic is HTTPS (TLS 1.3).
- ✅ **Public Key Pinning (SPKI SHA-256)** on all primary API domains, with a
  valid backup pin.
- ✅ Release builds reject user-installed CA / proxy certificates
  (Burp, Charles, mitmproxy) — anti-MitM validation.

## 3. Runtime Integrity

- ✅ Root/Magisk/jailbreak detection at startup; restrict sensitive/financial
  transactions when detected.
- ✅ **Play Integrity API** verifies the genuine, untampered app binary.
- ✅ Emulator detection on critical transaction flows.
- ✅ Release builds enable R8/ProGuard (`isMinifyEnabled = true`,
  `isShrinkResources = true`).

## 4. Authentication & Session

- Access tokens expire in **≤ 15 minutes**.
- High-value operations (transfers, payments, credential changes) require
  `BiometricPrompt` with a `CryptoObject` bound to a hardware Keystore key.
- Backend suspension/termination → app immediately clears local tokens and
  redirects to Login (remote kill-switch).

## 5. DevSecOps Hygiene

- ❌ Keystore passwords, aliases, `.jks`/`.keystore` files must NEVER enter Git.
- ✅ All staged commits must pass the Gitleaks pre-commit scan.

## When Reviewing Code — Flag These Violations

- `getSharedPreferences(...).edit().putString("token", ...)` (plaintext token)
- `OkHttpClient` / `fetch` configured to trust all certificates or accept
  user-added CAs in release builds
- Hardcoded API keys or keystore passwords in Kotlin/Dart/Swift source
- Long-lived access tokens (hours/days) or refresh tokens readable by any
  other app component
- Sensitive screens without `FLAG_SECURE`
