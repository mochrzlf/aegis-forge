🛡️ Aegis Forge Architecture

Banking-Grade Zero Trust IAM, Network Isolation & Dual Control Specification

🌐 Network & Container Isolation Topology

Hardened zero-public-port-leakage architecture. Database and Cache are strictly locked in private Docker bridge network.

Perimeter UFW & Caddy Proxy

Public exposure restricted strictly to Ports 80 (HTTP redirect) and 443 (HTTPS/QUIC). No direct client access to database or internal microservices.

Data Isolation Zero Port Leakage

PostgreSQL and Redis omit host port bindings in docker-compose.prod.yml. Accessible solely through Docker private bridge network.

Edge Defense Strict HTTP Headers

Injects HSTS (2 years with preload), X-Frame-Options: DENY, and X-Content-Type-Options: nosniff to eliminate clickjacking and MIME attacks.

🔑 Zero Trust IAM, RTR & Session Kill-Switch

Token lifecycle: Single-use Refresh Token Rotation (RTR), replay attack detection, and instantaneous JML revocation.

Storage Hygiene HttpOnly Cookie Only

Tokens are never exposed to browser localStorage, preventing XSS-based credential theft.

Replay Guard Token Family Invalidation

Presenting a revoked token triggers instant termination of all session siblings, neutralizing cloned token attacks.

Lifecycle Control Instant Session Kill

Employee departure (Leaver) transitions revoke all active credentials atomically without waiting for JWT TTL expiry.

👁️ Maker-Checker (Four-Eyes Principle) State Machine

Segregation of Duties (SoD) enforced by PostgreSQL Check Constraint maker_user_id <> checker_user_id.

Dual Control Four-Eyes Principle

No individual user can unilaterally authorize high-risk mutations (financial disbursement, role promotion, system parameters).

DB Guard Engine-Level Enforcement

The check constraint chk_maker_not_checker prevents bypass even if application-layer validation is misconfigured.

Auditability Non-Repudiation

Every decision records both Maker and Checker user IDs with timestamps in the append-only audit_logs table.
