# 📖 Plain-Language Glossary & Everyday Analogies

> **Software terms explained in plain English** — so anyone, even without a coding background, can understand how Aegis Forge works.

---

## 📦 1. Basic Concepts

| Term | What It Really Means | Everyday Analogy |
|---|---|---|
| **Template / Baseline** | A master copy you duplicate to create new projects | Like a **photocopy of a blank form** — you just fill in your specific answers. |
| **Repository (repo)** | The folder where all project files, history, and notes live | Like an **organized binder** holding every document of a project. |
| **Clone** | Copying a project repository from the internet to your computer | Like **downloading** an entire folder to your local laptop. |
| **Commit** | Saving a snapshot of your changes with an explanation | Like clicking **"Save"** and writing a date & sticky note on the page. |
| **Framework** | The underlying software engine that powers your application | Like a **car engine** — Aegis Forge is the "chassis, seatbelts, and safety rules". |

## 🔐 2. Security & Identity (IAM) Terms

| Term | What It Really Means | Everyday Analogy |
|---|---|---|
| **API Key** | A secret key that authorizes access to third-party services | Like a **physical house key** — anyone who holds it can open the door. |
| **Encryption** | Scrambling readable data into unreadable ciphertext | Like **writing a confidential message in a secret code** only the recipient can solve. |
| **Audit Trail** | An indelible log recording who performed what action and when | Like a **tamper-evident CCTV recording + visitor guestbook** that cannot be erased. |
| **RBAC (Role-Based Access Control)** | Restricting features and data based on user roles | Like **office keycards** — managers can access the server room, general staff cannot. |
| **Secrets** | Highly sensitive credentials (passwords, tokens, database keys) | Like your **bank ATM PIN** — never write it down where someone else can see it. |
| **Zero Trust** | Never trusting any user or network request by default; always verify | Like a **high-security building checkpoint** where IDs are checked at every single door. |
| **Maker-Checker (Dual Control)** | Requiring two distinct people to propose and approve high-risk actions | Like **two bank officers turning their keys simultaneously** to open a vault door. |
| **Refresh Token Rotation (RTR)** | Issuing a brand-new token upon every session refresh and detecting stolen tokens | Like a **one-time boarding pass** — if someone tries to board with an old pass, alarms trigger instantly. |
| **JML Kill-Switch** | Immediately terminating all active sessions when an employee or user is suspended | Like **deactivating an employee's access card instantly** the moment they leave the company. |

## 🤖 3. AI & Development Process Terms

| Term | What It Really Means | Everyday Analogy |
|---|---|---|
| **AI Coding Agent** | Autonomous AI capable of reading, writing, and testing code (Claude, Cursor, Hermes) | Like an **eager junior developer / personal assistant** who types very fast. |
| **PRD (Product Requirements Document)** | A clear document defining *what* the application must do | Like an **architectural blueprint** drawn before pouring concrete. |
| **OpenAPI Specification** | A formal contract describing API endpoints, inputs, and responses | Like a **restaurant menu** — listing exactly what dishes can be ordered and what ingredients come with them. |
| **Database Schema (`schema.sql`)** | The organized blueprint of tables, columns, and relationships in the database | Like an **office filing cabinet** — defining which folder holds what type of paper. |
| **CI/CD Pipeline** | Automated checks and tests that run whenever changes are saved | Like a **factory quality inspection line** — every car is tested before leaving the factory. |
| **STRIDE Threat Model** | Systematic evaluation of 6 cyber threat categories before writing code | Like a **security inspection** of all windows, doors, and fences before moving into a house. |

## 💻 4. Core Infrastructure Terms

| Term | What It Really Means | Everyday Analogy |
|---|---|---|
| **Docker & Containers** | Packaging software and all its dependencies into an isolated sandbox | Like a **standardized shipping container** — loads onto any truck or ship without repacking. |
| **PostgreSQL** | A powerful, reliable open-source relational database | Like a **secure, organized digital warehouse** for your business records. |
| **Redis** | An ultra-fast in-memory key-value data store | Like a **desktop workspace desk** — keeping frequently accessed papers within arm's reach instead of going to the warehouse. |
| **Git** | Distributed version control tracking every change across time | Like **"Track Changes" in Word**, but applied to thousands of files across an entire team. |
| **Makefile** | A list of short shortcut commands to run complex tasks | Like **speed dial on a phone** — press one shortcut to trigger a 10-step process. |
